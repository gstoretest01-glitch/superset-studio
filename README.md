# Superset Studio

Tôi cần làm 1 hệ thống thiết lập báo cáo và tích hợp superset. 
Mục tiêu: tích hợp superset phiên bản free mới nhất, có thể tự chủ động cấu hình màu sắc và kích thước của báo cáo. Superset hiện chưa có respon nên hệ thống này phải tự custom việc này. Trước hết nghiên cứu giúp tôi
